# Gather

Prepare um encontro por etapas. O formulário compartilha o rascunho, revela campos com erro e mantém os painéis visitados. Datas, cidades e arquivos usam os mesmos componentes na Web e no NativeScript. A lista de destinos demonstra paginação controlada.

O cadastro e o envio de arquivos são simulações locais; não há serviço remoto. A tela faz parte do Mavis alpha.5.

[Open Gather](https://mavis-ui.getcortexlabs.com/playground/#/showcase/gather)
