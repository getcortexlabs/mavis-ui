# Sessão de foco

Escolha um ambiente, ajuste a duração e prepare uma sessão. Os nove componentes iniciais participam desta pequena tela de consumo. O mesmo código Vue roda no NativeScript e na Web.

<a href="/playground/#/showcase/focus" target="_blank" rel="noopener">Abrir exemplo interativo ↗</a>

A tela usa dados locais de demonstração e não reproduz áudio. Os cartões selecionáveis representam ações únicas; slider e botões ficam fora deles. A aplicação controla os valores e o estado de preparação, enquanto os componentes controlam a renderização e as regras de interação. Trocar o tema preserva a seleção.
