# Atelier

Menos pressa. Mais presença. Uma edição editorial com serifas nos títulos e uma fonte de leitura no corpo. Alterne entre edição diurna e noturna: o cartão da citação mantém seu próprio tema e o cabeçalho externo continua independente.

<a href="/playground/#/showcase/studio" target="_blank" rel="noopener">Abrir o Atelier ↗</a>

Abra o caderno, preencha o e-mail e confirme a inscrição para explorar Sheet, Dialog e Toast no tema local. O conteúdo é uma demonstração: não há envio, cadastro ou persistência de e-mail. Os dados desaparecem quando a tela é desmontada.
