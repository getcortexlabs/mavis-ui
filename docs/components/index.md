# Components

Choose a component to try its variations, inspect its props and copy the example. Previews use the Web implementation; the same example files also run in the NativeScript catalog.

::: info In development
Experimental API, with no published package. [Start from a local checkout](../guide/foundation).
:::

| Component | Purpose |
| --- | --- |
| [Button](./button) | Actions with variants, sizes and interaction states. |
| [Slider](./slider) | Numeric selection with bounds and integer or fractional steps. |
| [Card](./card) | A themed surface for related content. |
| [Text](./text) | Typography, semantic colors and accessible text. |
| [Row](./row) | Arrange elements side by side with spacing and alignment. |
| [Column](./column) | Arrange content vertically while preserving its natural height. |
| [Box](./box) | Layer content in a single area. |
| [Screen](./screen) | A themed screen surface with optional scrolling. |
| [Reveal](./reveal) | Show or hide content with a short transition. |
