# Lustre

Colour, words and small moments. The shared Vue screen uses declared Mavis surfaces for gradients, a rolling counter, text entrance, loading decoration and a retained circular panel. It demonstrates replacing a target, removing and restoring it, retargeting borrowed values and changing the theme.

**Source development; not published in alpha.7.** See [requirements and platform limits](../guide/visual-motion). Android keeps loading placeholders static and circular content visible.
