# Gather

Prepare a gathering in steps. The form shares its draft, reveals invalid fields and retains visited panels. Dates, cities and files use the same components on Web and NativeScript. The destination list demonstrates controlled pagination.

Registration and uploads are local simulations with no remote service. This screen is available in source, not alpha.4.
