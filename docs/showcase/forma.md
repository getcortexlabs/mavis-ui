# Forma

An art edition configured with NumberInput, MultiSelect and Image. The same Vue screen runs on Web and NativeScript with Mavis and Midnight themes. Reservation is a local demonstration without a purchase or remote service.

The colour study uses one continuous value for background, radius and scale. Press multiplies the application's scale: `1.1 × 0.96`, returning to `1.1` on release. The recipe uses Jolt `0.1.0-rc.9`; interpolation does not run in a Vue frame loop.

Accordion uses Reveal's intrinsic height. The fixture covers dynamic content, reversal during closing, and editor identity through reversal. After a complete close, the editor unmounts; its draft belongs to the screen.

Available in Mavis `0.1.0-alpha.7`.

[Try Forma](https://mavis-ui.getcortexlabs.com/playground/#/showcase/forma)
