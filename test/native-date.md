# Native civil-date checks

Use the shared `DateCheck.vue` fixture (`examples/catalog/shared/pages/DateCheck.vue`) or the catalog Date Picker and Date Range Picker demos. Mount inside `MScreen`; keep a visible keyboard route back to the page. Native calendars use Mavis buttons and a horizontal ScrollView, not platform DatePicker views.

1. In Departure, type `2024-02-`, then `2024-02-30`. Preserve both drafts and keep the displayed model `2024-02-29`. Blur and verify the error. Correct to `2024-02-28`; verify model and actual editor match. Paste `02/03/2024`; reject it without locale guessing.
2. Open Departure's calendar while text editing. The keyboard dismisses. February 2024 is shown; Previous month is disabled at min. Select February 29, navigate Next to March, then cancel. Opening/navigation/cancel do not modify the date. Closing returns to the calendar opener without reopening the text keyboard.
3. Open Journey's start calendar. March 10 is unavailable; tapping it cannot commit or close. March 11 can commit. Selected day has visible border/background plus a readable selected accessibility value.
4. Enter Journey `2024-03-09` to `2024-03-11`: blocked interior March 10 keeps both drafts and the previous model. Set start `2024-03-12`: reversed pair is retained with an error. Set end `2024-03-12`: equal endpoints commit. Clear just the start: `{start:null,end:'2024-03-12'}`. Clear dates: both null.
5. Tighten bounds while Departure calendar is open. The cursor/month respects max February 20; existing model February 29 stays unchanged with an error. Change locale to pt-BR; labels update but editor order stays `AAAA-MM-DD`. Empty date opens January 2000 from its explicit snapshot.
6. Toggle readonly/disabled while calendar is open; it closes and blocked actions cannot mutate either draft or model. Toggle/unload the owning page while open and verify no remaining overlay. Reenter, open and choose normally. Parent rejects always retains its controlled value after a valid proposal.
7. Repeat in light and dark themes, normal and large system text, narrow portrait and landscape. Calendar columns retain native targets at least 48 dip; use horizontal scrolling to reach all seven columns, while the Sheet scrolls vertically. Inspect full day names, month/year wrapping, both endpoint labels, helper/error content and the clear button.
8. If hardware keyboard and screen reader are available, traverse actual native buttons/editor focus, activate dates, close and verify returned opener. Record exactly which input/assistive hardware was tested; fake renderer checks do not establish physical keyboard or spoken-output behavior.

Automated coverage: `test/date.spec.ts` checks civil arithmetic (leap days, century rules, extreme years and timezone changes), SSR and controlled drafts; `test/date-native.spec.ts` runs the real native calendar and shared state with primitive/platform bridge doubles. Device evidence must additionally verify text-entry and native ScrollView measurement, focus and actual editor values.
