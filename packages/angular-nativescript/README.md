# Mavis for Angular NativeScript

Experimental direct adapter for MBox, MRow, MColumn, MText, MButton and MInput. Uses native views, framework-owned state, scoped themes and Jolt motion through `@getcortexlabs/mavis/native`.

Available in RC.15. [Setup, exact tested versions, composition limits and lifecycle ownership](https://mavis-ui.getcortexlabs.com/guide/native-adapters). [Runnable consumer](https://github.com/getcortexlabs/mavis-ui/tree/main/examples/native-adapters). The CLI supports a direct iOS/Android starter for this framework; portable compilation remains unsupported.
