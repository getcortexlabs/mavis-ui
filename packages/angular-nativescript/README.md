# Mavis for Angular NativeScript

Experimental direct adapter for MBox, MRow, MColumn, MText, MButton and MInput. Uses native views, framework-owned state, scoped themes and Jolt motion through `@getcortexlabs/mavis/native`.

Unreleased after RC.14. [Setup, exact tested versions, composition limits and lifecycle ownership](https://mavis-ui.getcortexlabs.com/guide/native-adapters). [Runnable consumer](https://github.com/getcortexlabs/mavis-ui/tree/main/examples/native-adapters). This package does not enable a portable compiler or a creator preset.
