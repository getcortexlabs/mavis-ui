# Mavis core

Experimental shared package. Theme values, spacing resolution, and slider step conversion have no platform dependencies. The optional `/vue` entry provides the theme context, layout context, and common template types through Vue's renderer-independent runtime core.

NativeScript and Web applications must resolve a single Vue runtime instance. The example webpack config and Vite dedupe settings show this for a local monorepo checkout.

This package is private and has not been published to npm.
